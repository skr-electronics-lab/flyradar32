FlyRadar32: Standalone ESP32 ADS-B Aircraft Radar & Desktop Flight Tracker

Commercial and private aircraft continuously broadcast their real-time coordinates, altitude, speed, and heading over 1090 MHz ADS-B transponders. FlyRadar32 is a dedicated, standalone desktop aircraft radar station powered by an ESP32, an 8-pin 1.8-inch ST7735 SPI color TFT, non-blocking hardware LEDC PWM backlight dimming, and a precision FreeCAD 3D-printed desktop console.

1. Introduction to FlyRadar32

While smartphone flight apps and web maps are useful for occasional checks, having a dedicated physical radar instrument sitting on your workbench or desk delivers effortless real-time situational awareness. FlyRadar32 runs 24/7 without requiring an open browser tab or an active computer.

The ESP32 connects directly to your 2.4 GHz local Wi-Fi, queries live ADS-B flight feeds within your configurable geographic radius, calculates exact distance and bearing using spherical trigonometry (Haversine & Great Circle bearing), and sweeps active aircraft across a full 360-degree radar PPI screen.

3. Circuit Diagram & Hardware Pinout

The 8-pin ST7735 SPI display connects to the ESP32 hardware SPI bus (MOSI on GPIO 23, SCLK on GPIO 18). The display backlight pin (BLK) is wired to GPIO 21 to enable hardware PWM brightness control:

Module Pin ESP32 GPIO Signal Type Wiring Function
VCC VIN (5V) / 3V3 Power Module logic and backlight supply.
GND GND Ground Common circuit ground.
CS GPIO 5 Digital Output SPI Chip Select line (Active LOW).
RESET GPIO 4 Digital Output Hardware display reset pulse.
A0 / DC GPIO 2 Digital Output Data / Command selection.
SDA / MOSI GPIO 23 Hardware SPI Master Out Slave In data line (27 MHz).
SCK / SCLK GPIO 18 Hardware SPI SPI Serial Clock output.
LED / BLK GPIO 21 LEDC PWM Hardware PWM dimming (5,000 Hz, 0-100%).
Button UP GPIO 32 Input Pull-Up Scroll menu up / increase setting value.
Button SELECT GPIO 33 Input Pull-Up Toggle radar view mode / confirm selection.
Button DOWN GPIO 25 Input Pull-Up Scroll menu down / decrease setting value.

4. Live Breadboard Prototype Verification

Before assembling the electronics into the 3D-printed console, the complete circuit was prototyped and verified on a solderless breadboard. This step confirms SPI display timing, backlight PWM dimming, button debouncing, and Wi-Fi reception under real operating conditions:

Prototyping Recommendation

Keep the SPI wires between the ESP32 and the ST7735 under 15 cm in length. Operating the SPI bus at 27 MHz with long breadboard jumper wires can introduce signal ringing or screen artifacts.

6. 3D Desktop Enclosure & FreeCAD Design

The FlyRadar32 enclosure was parametrically designed in FreeCAD specifically for desktop visibility. It features an inclined 20-degree faceplate angle, internal screw mounting bosses for the ST7735, a snap-in cradle for the ESP32, and tactile button shafts:

3D Printing Parameters

  • Layer Height: 0.20 mm for main shell and bezel lid; 0.16 mm for button caps.
  • Perimeter Walls: 3 solid perimeters for mechanical stiffness.
  • Infill Density: 20% Gyroid or Grid infill.
  • Support Material: None required. All internal cable channels use self-supporting 45-degree chamfers.

7. FreeRTOS Multi-Provider ADS-B Engine

Many open flight tracker projects fail when a single public API endpoint experiences downtime or rate limits. FlyRadar32 is built on a fault-tolerant multi-provider engine supporting four independent ADS-B networks with instant automatic fallback:

  1. Flightradar24: Extensive global coverage with fast commercial data updates.
  2. ADS-B One: Unfiltered community feeder network offering real-time bounding box JSON queries.
  3. Airplanes.live: Open tar1090 feeder network with high update reliability and no rate limits.
  4. OpenSky Network: Academic ADS-B network providing worldwide coverage.
Dual-Core FreeRTOS Architecture

Core 0: Handles Wi-Fi connection state, HTTPS REST requests, chunked JSON streaming parser, and the local web dashboard server.
Core 1: Runs the high-speed radar display rendering pipeline at 30 FPS, polls physical push buttons, and calculates trigonometric target positions without jitter.

8. Hardware LEDC PWM Backlight Dimming

Instead of simple software on/off switching or noisy low-frequency dimming, the ST7735 backlight is driven by the ESP32's dedicated LED Control (LEDC) peripheral on GPIO 21. By running at 5,000 Hz with 8-bit resolution (0-255 steps), the display produces zero audible whine and zero visible flicker: 

#define TFT_BLK_PIN   21
#define PWM_CHANNEL   0
#define PWM_FREQ      5000
#define PWM_RES       8

void init_backlight() {
    ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RES);
    ledcAttachPin(TFT_BLK_PIN, PWM_CHANNEL);
    set_backlight_percent(80); // Default comfortable workstation brightness
}

void set_backlight_percent(uint8_t percent) {
    if (percent > 100) percent = 100;
    uint32_t duty = (uint32_t)(percent * 255) / 100;
    ledcWrite(PWM_CHANNEL, duty);
}
Interactive Brightness Control

Adjust the display brightness directly on the TFT using the physical UP/DOWN buttons in the Settings menu, or smoothly drag the real-time brightness slider inside the web dashboard.

9. Onboard Web Cockpit & Configuration

FlyRadar32 hosts a comprehensive, responsive web application served directly from the ESP32. When connected to your Wi-Fi, open your browser and visit http://flyradar32.local:

First-Boot Setup Workflow

  • Step 1 — Wi-Fi Hotspot: On initial power-on, connect your phone or laptop to the temporary Wi-Fi network FlyRadar32-Setup.
  • Step 2 — Wi-Fi Pairing: Enter your home Wi-Fi SSID and password in the captive portal. The ESP32 saves credentials to NVS flash and reboots.
  • Step 3 — Custom Location: Access http://flyradar32.local to set your home latitude and longitude, select your tracking range (10 km to 250 km), choose your preferred units (metric or nautical), and adjust screen sleep timers.

10. Conclusion & Open Source Resources

FlyRadar32 transforms an affordable ESP32 and a 1.8-inch ST7735 color display into an autonomous, real-time desktop aircraft radar. With its 4-provider failover engine, hardware PWM backlight dimming, and custom 3D enclosure, it makes a functional and attractive centerpiece for any electronics or aviation enthusiast's desk.

The entire project—including PlatformIO firmware source code, pre-compiled factory binary, 3D STL print files, and FreeCAD source files—is 100% open source under the MIT License.
