FlyRadar32: Standalone ESP32 ADS-B Aircraft Radar & Desktop Flight Tracker

Commercial and private aircraft continuously broadcast their real-time coordinates, altitude, velocity, and transponder telemetry over 1090 MHz ADS-B. In this complete step-by-step tutorial, we build FlyRadar32: an autonomous desktop aircraft radar station powered by an ESP32, an 8-pin 1.8-inch ST7735 SPI color TFT, non-blocking hardware LEDC PWM backlight dimming, a 4-tier fault-tolerant ADS-B telemetry engine, and a custom FreeCAD 3D-printed desktop console.

1. Introduction to FlyRadar32 & System Architecture

Browser flight tracking maps and mobile apps are suitable for checking an occasional flight, but keeping an open browser tab consumes workstation screen space and laptop battery. FlyRadar32 is an autonomous physical instrument engineered to run 24/7 on your desk or workshop bench.

The ESP32 connects directly to your 2.4 GHz local Wi-Fi, queries live ADS-B flight feeds within your configurable geographic radius, calculates exact distance and bearing using spherical trigonometry (Haversine & Great Circle bearing), and sweeps active aircraft across a full 360-degree radar PPI screen.

10. FreeRTOS Dual-Core Architecture & Radar Math

Rendering a 360-degree radar display with animated sweep lines while handling TLS HTTPS network requests requires clean separation of tasks. FlyRadar32 takes full advantage of the ESP32's dual Xtensa LX6 cores using FreeRTOS:

Dual-Core Task Separation

Core 0 (Networking & Web Engine): Manages the Wi-Fi stack, TLS HTTPS connections, streaming chunked JSON parsing, and the local AsyncWebServer dashboard.

Core 1 (Real-Time Display Pipeline): Drives the ST7735 color TFT at 30 FPS over hardware SPI (27 MHz), executes spherical trigonometry, handles push button interrupts, and updates range rings without frame stutter.

Spherical Radar Trigonometry

To place each aircraft on the radar screen, FlyRadar32 calculates distance using the Haversine formula and heading using the Great Circle initial bearing equation: 

// Distance in kilometers via Haversine
float dLat = radians(planeLat - homeLat);
float dLon = radians(planeLon - homeLon);
float a = sin(dLat / 2) * sin(dLat / 2) +
          cos(radians(homeLat)) * cos(radians(planeLat)) *
          sin(dLon / 2) * sin(dLon / 2);
float distanceKm = 6371.0 * 2.0 * atan2(sqrt(a), sqrt(1.0 - a));

// Great Circle Bearing in degrees (0 - 360)
float y = sin(dLon) * cos(radians(planeLat));
float x = cos(radians(homeLat)) * sin(radians(planeLat)) -
          sin(radians(homeLat)) * cos(radians(planeLat)) * cos(dLon);
float bearingDeg = fmod((degrees(atan2(y, x)) + 360.0), 360.0);

// Polar to Cartesian conversion for ST7735 screen (160x128 landscape)
int screenX = CX + (int)((distanceKm / maxRadiusKm) * RADAR_R * sin(radians(bearingDeg)));
int screenY = CY - (int)((distanceKm / maxRadiusKm) * RADAR_R * cos(radians(bearingDeg)));

11. Hardware LEDC PWM Backlight Dimming

Instead of simple software on/off switching or noisy low-frequency dimming, the ST7735 backlight is driven by the ESP32's dedicated LED Control (LEDC) peripheral on GPIO 15. By running at 5,000 Hz with 8-bit resolution (0-255 steps), the display produces zero audible whine and zero visible flicker: 

#define TFT_BLK_PIN   15
#define PWM_CHANNEL   0
#define PWM_FREQ      5000
#define PWM_RES       8

void init_backlight() {
    ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RES);
    ledcAttachPin(TFT_BLK_PIN, PWM_CHANNEL);
    set_backlight_percent(80); // Default comfortable brightness
}

void set_backlight_percent(uint8_t percent) {
    if (percent > 100) percent = 100;
    uint32_t duty = (uint32_t)(percent * 255) / 100;
    ledcWrite(PWM_CHANNEL, duty);
}
Dual Dimming Control

Adjust the display brightness directly on the TFT using the physical UP/DOWN buttons in the Settings menu, or smoothly drag the real-time brightness slider inside the web dashboard.

12. FreeCAD 3D Enclosure Assembly Guide

The FlyRadar32 enclosure was designed parametrically in FreeCAD specifically for desktop visibility. It features an inclined 20-degree faceplate angle, internal screw mounting bosses for the ST7735, a snap-in cradle for the ESP32, and tactile button shafts:

Assembly Sequence

  1. Print the 3 main STL files from the repository: Base_Shell.stl, Lid_Faceplate.stl, and Buttons.stl.
  2. Insert the 3 tactile button caps into the lid bezel wells.
  3. Seat the ST7735 1.8-inch TFT into the bezel mounting bosses and fasten with four M2 screws.
  4. Snap the ESP32 NodeMCU board into the base cradle. Route wiring to the display headers.
  5. Mate the top bezel with the base shell. The snap-fit joints lock securely without external glue.
