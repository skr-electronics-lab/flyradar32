FlyRadar32: Standalone ESP32 ADS-B Aircraft Radar & Desktop Flight Tracker

Commercial and private aircraft continuously broadcast position coordinates, altitude, velocity, and transponder telemetry over 1090 MHz ADS-B. In this complete build tutorial, we construct FlyRadar32: a dedicated standalone desktop aircraft radar station powered by an ESP32, an 8-pin 1.8-inch ST7735 SPI color TFT, non-blocking hardware LEDC PWM backlight dimming, a 4-tier fault-tolerant ADS-B telemetry engine, and a custom FreeCAD 3D-printed desktop enclosure.

1. Introduction to FlyRadar32 & Architecture

Browser flight tracking maps and mobile apps are suitable for checking an occasional flight, but keeping an open browser tab consumes workstation screen space and battery. FlyRadar32 is an autonomous physical instrument engineered to run 24/7 on your desk or workshop bench.

The ESP32 connects directly to your 2.4 GHz local Wi-Fi, queries live ADS-B flight feeds within your configurable geographic radius, calculates exact distance and bearing using spherical trigonometry (Haversine & Great Circle bearing), and sweeps active aircraft across a full 360-degree radar PPI screen.

4. Live Breadboard Prototype Verification

Before assembling the electronics into the 3D enclosure, the complete circuit was prototyped and verified on a solderless breadboard. This step confirms SPI display timing, backlight PWM dimming, button debouncing, and Wi-Fi reception under real operating conditions:

Prototyping Recommendation

Keep the SPI jumper wires between the ESP32 and the ST7735 under 15 cm in length. Operating the SPI bus at 27 MHz with long breadboard jumper wires can introduce signal ringing or screen artifacts.

7. FreeRTOS Dual-Core Architecture & Radar Math

Rendering a 360-degree radar display with animated sweep lines while handling TLS HTTPS network requests requires clean separation of tasks. FlyRadar32 takes full advantage of the ESP32's dual Xtensa LX6 cores using FreeRTOS:

Dual-Core Task Separation

Core 0 (Networking & Web Engine): Manages the Wi-Fi stack, TLS HTTPS connections, streaming chunked JSON parsing, and the local AsyncWebServer dashboard.

Core 1 (Real-Time Display Pipeline): Drives the ST7735 color TFT at 30 FPS over hardware SPI (27 MHz), executes spherical trigonometry, handles push button interrupts, and updates range rings without frame stutter.

Spherical Radar Trigonometry

To place each aircraft on the radar screen, FlyRadar32 calculates distance using the Haversine formula and heading using the Great Circle initial bearing equation: 

// Distance in kilometers via Haversine
float dLat = radians(planeLat - homeLat);
float dLon = radians(planeLon - homeLon);
float a = sin(dLat / 2) * sin(dLat / 2) +
          cos(radians(homeLat)) * cos(radians(planeLat)) *
          sin(dLon / 2) * sin(dLon / 2);
float distanceKm = 6371.0 * 2.0 * atan2(sqrt(a), sqrt(1.0 - a));

// Great Circle Bearing in degrees (0 - 360)
float y = sin(dLon) * cos(radians(planeLat));
float x = cos(radians(homeLat)) * sin(radians(planeLat)) -
          sin(radians(homeLat)) * cos(radians(planeLat)) * cos(dLon);
float bearingDeg = fmod((degrees(atan2(y, x)) + 360.0), 360.0);

// Polar to Cartesian conversion for ST7735 screen (128x160)
int screenX = centerX + (int)((distanceKm / maxRadiusKm) * radarRadiusPx * sin(radians(bearingDeg)));
int screenY = centerY - (int)((distanceKm / maxRadiusKm) * radarRadiusPx * cos(radians(bearingDeg)));

Altitude Color Coding

Aircraft blips on the radar display are dynamically color-graded based on altitude:

  • Red: Low altitude / landing approach (below 5,000 ft).
  • Orange: Climb / descent phase (5,000 ft to 15,000 ft).
  • Yellow: Transition flight levels (15,000 ft to 25,000 ft).
  • Green: High-altitude cruise (25,000 ft to 35,000 ft).
  • Cyan: Long-range transcontinental cruise (above 35,000 ft).

8. Multi-Provider ADS-B Failover Network

Many open flight tracker projects fail when a single public API endpoint experiences downtime or rate limits. FlyRadar32 is built on a fault-tolerant multi-provider engine supporting four independent ADS-B networks with instant automatic fallback:

  1. Flightradar24: Fast commercial data updates with global feeder coverage.
  2. ADS-B One: Unfiltered community feeder network offering bounding box JSON queries.
  3. Airplanes.live: Open tar1090 feeder network with high update reliability and no rate limits.
  4. OpenSky Network: Academic ADS-B network providing worldwide coverage.

If the primary provider fails to return valid telemetry within the timeout threshold, the engine automatically switches to the next configured provider. The active provider and failover state can be monitored in real time from the Station Diagnostics tab in the web cockpit.

9. Hardware LEDC PWM Backlight Dimming

Instead of simple software on/off switching or noisy low-frequency dimming, the ST7735 backlight is driven by the ESP32's dedicated LED Control (LEDC) peripheral on GPIO 21. By running at 5,000 Hz with 8-bit resolution (0-255 steps), the display produces zero audible whine and zero visible flicker: 

#define TFT_BLK_PIN   21
#define PWM_CHANNEL   0
#define PWM_FREQ      5000
#define PWM_RES       8

void init_backlight() {
    ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RES);
    ledcAttachPin(TFT_BLK_PIN, PWM_CHANNEL);
    set_backlight_percent(80); // Default comfortable workstation brightness
}

void set_backlight_percent(uint8_t percent) {
    if (percent > 100) percent = 100;
    uint32_t duty = (uint32_t)(percent * 255) / 100;
    ledcWrite(PWM_CHANNEL, duty);
}
Dual Dimming Control

Adjust the display brightness directly on the TFT using the physical UP/DOWN buttons in the Settings menu, or smoothly drag the real-time brightness slider inside the web dashboard.

10. Onboard Web Cockpit & First-Boot Configuration

FlyRadar32 hosts a comprehensive, responsive web application served directly from the ESP32. When connected to your Wi-Fi, open your browser and visit http://flyradar32.local:

First-Boot Setup Workflow

  • Step 1 — Wi-Fi Hotspot: On initial power-on, connect your phone or laptop to the temporary Wi-Fi network FlyRadar32-Setup.
  • Step 2 — Wi-Fi Pairing: Enter your home Wi-Fi SSID and password in the captive portal. The ESP32 saves credentials to NVS flash and reboots.
  • Step 3 — Custom Location: Access http://flyradar32.local to set your home latitude and longitude, select your tracking range (10 km to 250 km), choose your preferred units (metric or nautical), and adjust screen sleep timers.
